# Douglas Andrade — Portfólio Profissional

Site de portfólio pessoal desenvolvido para apresentar serviços, projetos e facilitar o contato com clientes.

🔗 **Acesse:** [portfolio-douglas-alpha.vercel.app](https://portfolio-douglas-alpha.vercel.app)

---

## Sobre o projeto

Landing page profissional criada para divulgar serviços de desenvolvimento web freelancer. O objetivo é converter visitantes em clientes através de um design corporativo, apresentação clara dos serviços e um formulário de contato integrado ao WhatsApp.

---

## Seções

- **Hero** — Apresentação com badge de disponibilidade e card de código
- **Sobre** — Perfil profissional com diferenciais
- **Serviços** — Sites, Sistemas Web, Integrações & APIs e Soluções com IA
- **Como funciono** — Processo em 3 passos: Conversa → Desenvolvimento → Entrega
- **Projetos** — Cases reais com tecnologias utilizadas
- **Contato** — Formulário que abre o WhatsApp com a mensagem já formatada

---

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, animações, grid, flexbox)
- JavaScript vanilla (Intersection Observer, WhatsApp redirect)
- Google Fonts — Inter
- Deploy via [Vercel](https://vercel.com)

---

## Funcionalidades

- Design responsivo (mobile, tablet e desktop)
- Navbar com efeito de scroll
- Animações de entrada ao rolar a página
- Formulário de contato integrado ao WhatsApp — a mensagem chega organizada com nome, empresa, e-mail, tipo de serviço e descrição do projeto
- Open Graph configurado para prévia ao compartilhar o link
- Favicon personalizado com as iniciais DA
